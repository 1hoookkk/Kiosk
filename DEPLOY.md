# Harvey Norman Kiosk - Quick Deploy

## 🚀 Instant Deploy Options

### Option 1: Deploy to Vercel (1-Click)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/1hoookkk/Kiosk)

Click the button above to deploy instantly!

### Option 2: Open Locally Right Now

Just open `index.html` in any browser - it works immediately!

### Option 3: Quick Share via Vercel CLI

```bash
# Install Vercel CLI (one time)
npm i -g vercel

# Deploy (takes 30 seconds)
vercel --prod
```

You'll get a URL like: `https://your-kiosk.vercel.app`
