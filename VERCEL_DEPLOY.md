# Deploy to Vercel - Super Easy!

## Method 1: One Command (Fastest)

```bash
cd /home/user/Kiosk
npx vercel --prod
```

That's it! You'll get a URL like: `https://your-kiosk.vercel.app`

## Method 2: Drag & Drop (No Terminal)

1. Go to [vercel.com](https://vercel.com)
2. Click "Add New" → "Project"
3. Drag the `index.html` file into the upload area
4. Click "Deploy"
5. Done! You get a live URL instantly

## Update Existing Vercel Project

If you want to update your existing Vercel app at:
`showroom-kiosk-5k11j9n5h-tysons-projects-99c0961c.vercel.app`

```bash
# Link to your existing project
vercel link

# Deploy update
vercel --prod
```

## Auto-Deploy from GitHub (Recommended)

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import your GitHub repo: `1hoookkk/Kiosk`
3. Click "Deploy"

Now every time you push to GitHub, Vercel auto-deploys! 🚀
